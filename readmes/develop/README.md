# BrowserTranslate documentation

The [README](../../README.md) covers what the extension is, how to install it and how to get started. These pages hold the detail, in English.

- **[Usage guide](./usage.md)** — the selection card, full-page translation, video subtitles, languages, providers and models, thinking controls and base prompts.
- **[Free translation services](./free-services.md)** — what the Microsoft and Google options are, and what they are not.
- **[Architecture, privacy and validation](./architecture.md)** — where requests run, what is stored, and how model responses are checked.
- **[Building from source](./building.md)** — development commands, the Firefox build and packaging.

Release notes are in the [changelog](../../CHANGELOG.md). Bugs and requests belong in [Issues](https://github.com/Lewen-Cai/browser-translate/issues); please remove API keys and private page content from reports.
