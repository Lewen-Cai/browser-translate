<a id="why"></a>
## Зачем BrowserTranslate?

Используйте удобного провайдера без обязательной подписки на расширение и без промежуточного сервера нашего проекта.

- **Своя модель и ключ:** подключайте OpenAI-совместимый endpoint или локальную среду. Совместимость зависит от endpoint и модели.
- **Прямое соединение:** текст отправляется из браузера выбранному провайдеру. Проект не управляет сервером-посредником.
- **Без телеметрии:** расширение не собирает аналитику, удалённые отчёты об ошибках и логи.
- **Редактируемый базовый промпт:** просматривайте стандартный текст и создавайте шаблоны. Общая база действует во всех режимах LLM; внутренние правила словаря и формата остаются под управлением расширения.

<a id="features"></a>
## Возможности

- **Можно начать без API-ключа:** Microsoft и Google включены изначально, новая установка использует Microsoft во всех трёх режимах. Это неофициальные публичные endpoints: прочтите [предупреждение](#free-engines).
- **Отдельный сервис для каждой задачи:** выделенный текст, вся страница и субтитры могут использовать разных провайдеров. Несколько конфигураций сохраняются без повторного ввода при переключении.
- **Перевод выделения:** выделите текст и нажмите всплывающий значок либо включите режим клавиш. Обычный текст выводится потоком, оригинал расположен сверху. Карточка позволяет копировать, переводить заново и временно менять провайдера/язык. Глобальные настройки не меняются; повторный перевод обходит кэш.
- **Стабильная и перемещаемая карточка:** размеры задаются в Общие → Внешний вид. Оригинал и перевод прокручиваются независимо, оригиналу отводится не более 30% общей области. Ожидание показано компактно. Закрепление сохраняет карточку при прокрутке и кликах снаружи; её можно перетащить за ручку.
- **Двуязычная страница:** перевод вставляется под оригиналом в основном содержимом, обычно без навигации, шапки и подвала. Обработка постепенно следует за видимой областью. Используйте Текущая страница → Двуязычный перевод в popup или **Alt+A** в режиме клавиш.
- **Словарь для коротких выделений:** модель может дать перевод, произношение, часть речи, значения и пример. Явные абзацы, несколько строк и фрагменты кода получают только инструкции перевода. Обычные сервисы не создают словарные статьи.
- **Смешанные языки разрешены:** совпадение языка исходника и цели не блокирует запрос. Региональная адаптация зависит от модели или сервиса.
- **Локальные настройки и кэш:** срок хранения меняется в Настройки → Данные. Импорт/экспорт JSON включает настройки и промпты, но не кэш и по умолчанию не ключи API.
- **Компактный интерфейс:** светлая/тёмная тема вручную или по системе; пять страниц — Общие, Перевод, Провайдеры, Субтитры, Данные. Интерфейс использует системные шрифты, код и endpoints — моноширинные.

<a id="subtitles"></a>
### Субтитры видео

Переводятся существующие дорожки **YouTube**, **облачных записей Zoom**, **записей курсов Canvas** и совместимых плееров с доступными `<track>`/TextTrack. Поддержка зависит от плеера и дорожки; проверены не все встроенные плееры. **Распознавание речи из аудио не выполняется.**

Нажмите значок перевода в плеере и включите перевод субтитров. Если подходящей панели нет, кнопка появится в углу видео. На YouTube сначала включите встроенные субтитры (CC), чтобы загрузилась дорожка; другим плеерам тоже может требоваться её активация. Поддерживаются авторские и доступные автоматические субтитры; последовательные фрагменты ASR собираются в предложения.

Оригинал и перевод накладываются на видео и перемещаются за ручку. Положение сохраняется и в полноэкранном режиме; видимые элементы управления обходятся. Приоритет получают реплики возле текущей позиции, после перемотки задачи перестраиваются. Распознанные подписи говорящих сохраняются без перевода. Задержка зависит от видео и провайдера, фиксированное время ответа не гарантируется.

Меню плеера и **Настройки → Субтитры** управляют двуязычным режимом/только оригиналом/только переводом, порядком строк, непрозрачностью, размером, цветом, шрифтом и толщиной каждой строки. В настройках доступны предпросмотр в реальном времени, точные числовые поля, небольшая палитра, HEX и кнопка сброса.

<a id="languages"></a>
### Языки

**56 целей перевода** не зависят от **14 языков интерфейса**, перечисленных сверху. Интерфейс может следовать языку браузера. Поиск в popup, настройках и карточке понимает собственные, английские и локализованные названия, коды и обозначения вариантов английского. RTL-названия сохраняют направление письма без смещения всей строки меню.

Английский разделён на варианты **США, Великобритании и Австралии**; прежний общий `en` переносится в американский английский. Китайский разделён на **упрощённое и традиционное письмо**. LLM получает региональные требования к написанию и лексике. Если бесплатный сервис не поддерживает вариант, он молча использует общий английский, не меняя провайдера.

<a id="architecture"></a>
## Архитектура

<p align="center"><img src="../assets/framework.png" alt="Архитектура BrowserTranslate и прямые соединения с провайдерами" width="760"></p>

LLM- и машинный перевод выполняют запросы через **фоновый service worker**. JavaScript сайта не получает API-ключ. Контентные скрипты показывают результаты и интегрируются со страницей/плеером; получение субтитров конкретного сайта может идти также в контекстах контентного скрипта или страницы. У проекта нет промежуточного сервера.

<a id="installation"></a>
## Установка

Для **настольных браузеров на Chromium**, включая Chrome, Edge, Brave и Arc. Firefox пока не поддерживается.

1. Скачайте последний `.zip` из [Releases](https://github.com/Lewen-Cai/browser-translate/releases).
2. Распакуйте в папку, которую будете сохранять.
3. Откройте `chrome://extensions` или управление расширениями, включите **Режим разработчика**, выберите **Загрузить распакованное расширение** и укажите папку.

### Ручное обновление

Распакованные расширения не обновляются автоматически. Распакуйте новый архив поверх прежней папки, нажмите **Обновить/перезагрузить** на странице расширений и обновите открытые веб-страницы. Управляемая установка самостоятельно размещённых расширений в Windows/macOS обычно требует корпоративной политики; загрузка распакованной папки — другой механизм.

В заголовке настроек находятся версия и ручная проверка. GitHub опрашивается только по нажатию; при наличии более новой версии предлагается архив, без автоматической установки. В popup номер версии не дублируется.

<a id="configuration"></a>
## Настройка

После установки все режимы используют Microsoft. Для своей модели:

1. Откройте popup и нажмите значок настроек.
2. В **Провайдеры** включите сервис и задайте endpoint, модель и ключ API. Локальная среда не требует ключа. Активные строки показывают состояние/задержку: эта проверка обращается к провайдеру.
3. В **Перевод → Сервисы перевода** отдельно назначьте провайдера выделению, странице и субтитрам.
4. Выберите язык и выделите текст на поддерживаемой странице. Для клавиатуры включите соответствующий режим в **Общие**: **Alt+T** переводит выделение, **Alt+A** — страницу. Оба сочетания работают только в этом режиме.

Popup содержит язык, переключатель перевода текущей страницы и сервисы. Способ активации и клавиши доступны только в настройках. Для неподдерживаемых страниц перевод отключён; отсутствие контентного скрипта сопровождается просьбой обновить страницу. Промпты и назначения находятся в Перевод, учётные данные — в Провайдеры, оформление — в Субтитры, кэш/импорт/экспорт — в Данные.

### Провайдеры и управление рассуждениями

Предустановки: **OpenAI, Claude, Gemini, DeepSeek, Moonshot, Zhipu, Qwen, SiliconFlow, OpenRouter, Mistral, opencode**. Локально: **LM Studio, Ollama, llama.cpp, vLLM**. Другие совместимые сервисы подключаются через свой endpoint.

Адреса различают регионы и тарифы: opencode Zen/Go, Qwen в Пекине, Сингапуре, Гонконге и Виргинии, а также Token Plan. Аккаунты, ключи и каталоги моделей не обязательно взаимозаменяемы. Поддерживаемые провайдеры допускают URL конкретного рабочего пространства.

Где это поддерживается, расширение по умолчанию запрашивает отключение рассуждений и предлагает **Low / Medium / High / XHigh / Max**, сопоставленные с параметрами провайдера. Для своего/локального сервера выберите формат параметра или **Ничего не отправлять**. Без поддерживаемого управления действует настройка сервера. Поддержка, задержка и оплата токенов рассуждений зависят от endpoint/модели, а не только от переключателя.

<a id="prompts"></a>
### Базовый промпт

В **Перевод → Базовый промпт** список шаблонов расположен рядом с редактором, а в узком окне — над ним. Стандартный шаблон виден, но доступен только для чтения. **Создать** позволяет начать с него или с пустого текста. Пояснение находится под редактором внутри карточки. Выбор шаблона лишь открывает его; используемый промпт отмечен отдельно.

- **Сохранить и применить** сохраняет черновик и сразу использует его.
- **Сохранить изменения** обновляет уже используемый промпт.
- **Применить промпт** использует сохранённый шаблон; для уже активного кнопка отключена.
- **Отмена** отбрасывает локальные правки.
- **Действия с шаблоном** включают сохранение без применения, дублирование, замену черновика стандартным текстом и удаление. Разрушительные операции требуют подтверждения; удаление активного шаблона возвращает стандартный.

Свои инструкции **заменяют** базу, а не дописываются к ней. Расширение сохраняет целевой язык, региональные правила, маршрутизацию и формат; внутренние протоколы не редактируются. Противоречивые инструкции или слабая модель могут давать несовершенный результат. `{{...}}` остаётся обычным текстом, подстановки переменных нет.

Локально сохраняются до **20 шаблонов**, по **12 000 символов** каждый. Они влияют только на LLM, не на обычный перевод Microsoft/Google. Изменённые промпты имеют отдельные записи кэша; экспорт включает шаблоны и активный выбор.

<a id="validation"></a>
### Проверка ответов

Явные фрагменты связного текста не получают словарные инструкции. Для коротких выделений модель выбирает режим, но статья должна соответствовать всему выделению, а не одному слову внутри. Подозрительный структурированный вывод буферизуется и проверяется; карточка получает явный тип результата вместо догадки по `{`.

Неверный формат ответа на выделение допускает не более **одного исправляющего запроса обычного текста**. Ошибочный пакет страницы/субтитров заменяется **одним текстовым запросом на каждый незакэшированный сегмент**. Это может расходовать дополнительные токены; сетевые повторы учитываются отдельно. Повторная ошибка показывается сообщением, а не исходным JSON протокола, и не кэшируется.

ID пакета должны быть уникальны и полны; ответы восстанавливаются в порядке ввода, числа и объекты не приводятся насильно к строкам перевода. Ключи кэша с учётом протокола и проверка чтения изолируют старые непроверенные ответы. Структуры, содержащиеся в самом исходнике, по-прежнему можно переводить как текст.

**Проверка формата не гарантирует смысловую точность и обнаружение всех пропусков.** Название языка — локальная подсказка с осторожной отметкой смешанных письменностей; оно не блокирует запрос и не выбирает его маршрут.

<a id="free-engines"></a>
### Бесплатные сервисы

Microsoft и Google используют `edge.microsoft.com` и `translate-pa.googleapis.com`.

- **Это не официальные API:** адреса обслуживают собственные функции веб-/браузерного перевода компаний, без публичного контракта для расширения.
- **Нет аффилированности или одобрения:** проект не связан с Microsoft/Google, не спонсируется и не одобрен ими. Марки принадлежат владельцам и лишь обозначают сервис.
- **Доступность не гарантируется:** возможны изменения или остановка без предупреждения. Можно перейти на свою модель, доступность которой также зависит от провайдера.
- **Текст отправляется сервису:** действуют его условия и политика конфиденциальности. Для чувствительных данных выбирайте подходящий собственный endpoint.
- **Без гарантий:** предоставляется как есть, на ваш риск. Для коммерческой или массовой работы используйте официальные API с необходимыми лицензиями.

Microsoft выбран для удобного первого запуска. Назначенный вашей модели режим больше не использует эти публичные адреса перевода.

<a id="privacy"></a>
## Приватность и локальные данные

Отсутствие посредника и телеметрии **не означает полностью локальную обработку**. Облачный провайдер получает отправленный текст; локальная среда может оставить модельную обработку на компьютере. Субтитры запрашиваются у видеосайта, ручное обновление — у GitHub. Сервисы получают обычные сетевые метаданные, например IP-адрес.

Настройки, ключи API и кэш находятся в `chrome.storage.local`. **Расширение не шифрует API-ключи.** По умолчанию экспорт их исключает; включение создаёт текстовый файл без шифрования, который нужно хранить в тайне. Кэш не экспортируется, просматриваемая история переводов не ведётся.

<a id="development"></a>
## Разработка

```bash
pnpm install
pnpm dev          # Сборка с наблюдением: .output/chrome-mv3-dev/
pnpm test         # Тесты с наблюдением
pnpm test:run     # Однократный запуск тестов
pnpm typecheck    # Генерация типов WXT + TypeScript
pnpm lint
pnpm build        # Рабочая сборка: .output/chrome-mv3/
```

Загрузите папку результата как распакованное расширение. При смене сборки перезагрузите расширение и страницы. Изменения описаны в [CHANGELOG.md](../CHANGELOG.md), проблемы и пожелания — в [Issues](https://github.com/Lewen-Cai/browser-translate/issues). Удаляйте из отчётов ключи и личное содержимое страниц.
