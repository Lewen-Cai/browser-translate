> 开源、隐私优先的浏览器翻译扩展。自带 LLM API Key，零中转，零遥测。

## 为什么

市面上的翻译扩展要么把 LLM 锁在付费墙后、要么把你的文本经它们的服务器中转、要么把决定翻译质量的 prompt 藏起来。BrowserTranslate 反对以上三点。

- **自带 Key**：兼容所有 OpenAI 协议的服务。已内置：OpenAI、Claude、Gemini、DeepSeek、Moonshot、Zhipu、Qwen、SiliconFlow、OpenRouter、Mistral、opencode；本地运行时：LM Studio、Ollama、llama.cpp、vLLM。其余一律可作为自定义端点接入。
- **零中转**：翻译请求由你的浏览器直接打到你配置的服务方，我们没有服务器
- **零遥测**：不接入任何统计、错误上报、远程日志
- **Prompt 开放**：翻译 prompt 固定但完全开源，语域与主题由模型自行判断

## 功能

- **无需 API Key 即可使用**——微软和谷歌开箱即启用，装好就能翻译，且完全免费。想要词典查询或更好的译文时，再接入自己的大模型。使用前请阅读下方[关于免费引擎的说明](#关于免费引擎)。
- **多服务商并存，按用途分别路由**——想配几个就配几个，然后为每个场景单独指定由谁来答：划词卡片、整页翻译、视频字幕互不影响。整页用免费服务，真正在意的那一段用你最好的模型。
- 划词翻译（图标二段触发，或纯快捷键模式）。卡片顶部标明本次是「哪种语言 → 哪种语言」，原文与译文并列，并自带控件：只对这张卡片切换服务商或目标语言、复制译文、重新翻译。这些选择只在这张卡片上生效，绝不写回设置。卡片可固定（pin）——固定后停在屏幕上，滚动页面也不会跟着跑掉，点击别处也不会消失，挡住正文时拖动把手即可挪开。
- 整页双语翻译——原地翻译页面正文（导航栏、页眉、页脚等保持原样），每段译文显示在原文下方；随滚动逐步加载（仅翻译可见部分）；已是目标语言的段落自动跳过；可从弹窗（"翻译页面" / "显示原文"）开关，或在「快捷键」触发模式下用 **Alt+A** 热键
- 流式输出（SSE）
- 服务商列表在「设置 → 翻译」里，是一个可搜索的固定高度面板：打开开关启用，点进去填端点、Key 和模型，启用后该行会自己报告延迟。有多个区域或套餐的供应商以端点形式提供选择——包括 opencode，其 Zen 与 Go 是两套独立计费、模型目录也不同的产品。本地运行时无需 API Key。
- 模型思考默认关闭——混合推理模型（如 DeepSeek V4）无需为每次翻译先"思考"，出字更快、也不为隐藏的思考 token 计费；支持的服务商（Claude、Gemini、DeepSeek、Zhipu、Qwen、SiliconFlow、OpenRouter、opencode）可按服务商开回思考，并提供 Low / Medium / High / XHigh / Max 五档强度（自动映射到各服务商的原生参数）
- 词典模式——由模型在一次流式请求中自动判定选区是"查词"还是"翻译"，词典结果展示该词条的正式译名、音标、词性、释义和例句
- 设置导出 / 导入（设置 → 数据）——将配置导出为 JSON 文件，在其他设备导入；API Key 默认不导出（勾选后可包含，附明文提示）
- **视频字幕翻译** — 点击播放器控制栏里的翻译按钮（语言图标）打开字幕菜单，再打开开关即可翻译视频已有的字幕。支持 YouTube、Zoom 云录制、Canvas 课程录像，以及任何用标准 `<track>` 提供字幕的播放器；遇到没有可插入控制栏的播放器，按钮会落在画面角落。双语两行由扩展自己绘制在播放器上（原文在上、译文在下），拖动字幕上方的把手可以把字幕移到画面任意位置，越过画面中线后会改为吸附顶部。位置会被记住，全屏下同样生效；控制栏出现时字幕会自动上移让开。除 UP 主上传的人工字幕外，自动生成（ASR）的字幕也支持：ASR 是一次几个词地送来的，会先重新拼成完整句子再翻译。只翻译播放头附近的字幕，因此长视频也能在一两秒内出字幕，拖动进度条会立刻跟到新位置。在 YouTube 上请先打开字幕（CC），播放器才会加载字幕轨；其他站点无需先开任何开关。若转录里标了说话人，姓名会被摘出翻译流程、原样贴回——模型每次给出的音译写法都不一样，同一个人每隔几秒换一个名字反而比不显示更难跟。字幕样式——显示模式（双语／仅原文／仅译文）、译文位置、背景不透明度，以及原文与译文各自的字号、颜色、字体和字重——在菜单的"字幕样式"页里调整，设置 → 视频 里也有同样的选项。（只翻译已有字幕；不做语音识别。）
- 翻译缓存（可配 TTL）
- 明暗外观跟随系统或手动指定；拉丁文字用 JetBrains Mono，中日韩用思源宋体，并按语言分别配置回退栈——中文、日文、韩文各用各自的字形，不会互相串用
- 34 种目标语言，与界面语言分开设置——你读什么语言，和扩展用什么语言对你说话，是两件事
- 界面支持 8 种语言（简体/繁体中文、English、日本語、한국어、Español、Français、Deutsch），自动跟随浏览器语言

## 安装

### Chrome / Edge / Brave / Arc

1. 在 [Releases](https://github.com/Lewen-Cai/BrowserTranslate/releases) 下载最新 `.zip`
2. 解压
3. 打开 `chrome://extensions` → 开启开发者模式 → "加载已解压的扩展程序" → 选解压后的目录

## 配置

装好即可翻译——三个场景默认都走微软，直接划词就能用。以下步骤只在你想接入自己的模型时才需要。

1. 点扩展图标，再点右上角的设置按钮进入设置页。
2. 在**「翻译 → 服务商」**里找到想用的厂商，打开开关；点进去填 **模型** 和 **API Key**（本地运行时无需 Key），若该厂商有多个区域或套餐，在这里选择端点。启用后该行会自己报告延迟。
3. 在**「通用 → 路由」**里指定每个场景由谁来答：**划词卡片**、**整页翻译**、**字幕**。三者互不影响——免费服务即时且零成本，正适合整页或一小时的字幕；而模型能读上下文，也是唯一能把单个词答成词典条目的一类。
4. 在任意网页选中文字 → 点蓝色图标 → 看到译文。（想用快捷键？在设置里把触发模式切为「快捷键」，此时用快捷键代替图标。）

popup 里留的是常改的东西：目标语言、触发模式、整页翻译开关和路由。其余（界面语言、缓存、字幕外观、数据导出）都在完整设置页。

### 关于免费引擎

微软和谷歌两个选项调用的是公开翻译端点（`edge.microsoft.com`、`translate-pa.googleapis.com`）。依赖它们之前请先了解：

- **它们不是官方 API。** 这些是两家公司自己的网页 / 浏览器翻译功能所用的端点，没有公开的服务契约。
- **本项目与微软、谷歌没有任何隶属、赞助或授权关系。** 相关名称与标识归其各自所有者，此处仅用于标明你所选择的服务。
- **它们可能随时变更或失效**，且不会有任何通知。真出现这种情况，在设置里换个引擎即可——你自己的 API 不受影响。
- **你翻译的文本会被发送到这些服务**，适用的是它们各自的条款与隐私政策，而非本项目的。如果所译内容对此敏感，请改用自己的端点。
- **不作任何担保。** 这些选项按现状提供，风险自负。若用于商业或大批量场景，请使用厂商官方的、获得授权的 API。

路由默认全部指向微软，只是为了让刚装好的扩展就能用。任何一个场景改由你自己的服务商来答，该场景就不再涉及以上任何一条。

## 开发

```bash
pnpm install
pnpm dev          # 开发构建，监听 src/，输出到 .output/
pnpm test         # 监听模式跑测试
pnpm build        # 生产构建
```

加载 `.output/chrome-mv3-dev/`（开发）或 `.output/chrome-mv3/`（生产）作为未打包扩展。
