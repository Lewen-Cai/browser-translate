<a id="why"></a>
## BrowserTranslate를 선택하는 이유

확장 프로그램 구독이나 저희가 운영하는 중계 서비스를 거치지 않고 원하는 번역 제공업체를 이용하세요.

- **직접 선택하는 모델과 키**: OpenAI 호환 엔드포인트나 로컬 실행 환경에 연결합니다. 실제 호환성은 엔드포인트와 모델에 따라 다릅니다.
- **직접 연결**: 번역할 텍스트는 브라우저에서 선택한 제공업체로 바로 전송됩니다. 프로젝트는 중계 서버를 운영하지 않습니다.
- **원격 측정 없음**: 사용 분석, 원격 오류 보고, 원격 로그 수집을 하지 않습니다.
- **편집 가능한 기본 프롬프트**: 기본 내용을 확인하고 사용자 템플릿을 만들 수 있습니다. 모든 LLM 번역에 하나의 기본 지침을 적용하며, 사전 및 출력 형식 규칙은 확장 프로그램이 관리합니다.

<a id="features"></a>
## 기능

- **API 키 없이 시작**: Microsoft와 Google 번역 서비스가 기본 활성화되어 있으며, 새 설치는 세 번역 모드 모두 Microsoft를 사용합니다. 비공식 공개 엔드포인트이므로 [무료 서비스 안내](#free-engines)를 먼저 읽어 주세요.
- **용도별 번역 엔진**: 선택 카드, 전체 페이지, 영상 자막에 각각 다른 제공업체를 지정합니다. 여러 설정을 저장하므로 전환할 때 다시 입력할 필요가 없습니다.
- **선택 영역 번역**: 텍스트 선택 후 떠 있는 아이콘을 누르거나 단축키 모드를 사용합니다. 일반 번역은 스트리밍되며 원문은 결과 위에 표시됩니다. 복사, 재번역, 제공업체와 대상 언어를 카드에서 바꿀 수 있습니다. 카드 내 선택은 전역 설정을 바꾸지 않으며, 재번역은 캐시를 건너뜁니다.
- **고정 크기와 이동**: 「일반 → 모양」에서 크기를 설정합니다. 원문과 번역은 독립적으로 스크롤하고, 원문은 공유 본문 영역의 최대 30%를 차지합니다. 대기 중에는 작은 로딩 상태만 표시됩니다. 고정하면 스크롤하거나 바깥을 눌러도 유지되며 손잡이로 이동할 수 있습니다.
- **전체 페이지 이중 언어 번역**: 본문에 번역을 삽입하고 원문을 위에 남깁니다. 탐색 메뉴, 머리글과 바닥글 등은 보통 제외하며, 화면 주변을 스크롤에 맞춰 점진적으로 처리합니다. 팝업 「현재 페이지 → 이중 언어 번역」 스위치 또는 단축키 모드의 **Alt+A**로 전환합니다.
- **짧은 선택 영역의 자동 사전 조회**: 모델은 단어나 짧은 용어의 번역, 발음, 품사, 뜻과 예문을 제공할 수 있습니다. 명확한 문단, 여러 줄, 코드 형태의 선택은 번역만 수행합니다. 일반 번역 서비스는 사전 항목을 만들지 않습니다.
- **혼합 언어 허용**: 원문과 대상 언어가 같다는 이유로 요청을 막지 않습니다. 지역별 표현 변환 품질은 모델이나 서비스에 따라 다릅니다.
- **로컬 설정과 캐시**: 「설정 → 데이터」에서 유효 기간을 조정합니다. 설정과 사용자 프롬프트를 JSON으로 내보내고 가져올 수 있습니다. 캐시는 제외하며, API 키도 명시적으로 선택하지 않으면 내보내지 않습니다.
- **간결한 인터페이스**: 밝게／어둡게를 시스템에 맞추거나 직접 선택합니다. 일반, 번역, 제공업체, 자막, 데이터의 다섯 설정 페이지를 제공합니다. UI는 시스템 글꼴, 코드와 엔드포인트는 고정폭 글꼴을 사용합니다.

<a id="subtitles"></a>
### 영상 자막

**YouTube, Zoom 클라우드 녹화, Canvas 강의 녹화**, 그리고 표준 `<track>`／TextTrack으로 접근 가능한 자막을 제공하는 호환 플레이어를 지원합니다. 지원 여부는 플레이어와 자막 트랙에 따라 다르며 모든 임베디드 플레이어를 시험한 것은 아닙니다. **기존 자막만 번역하며 음성을 직접 전사하지 않습니다.**

플레이어의 번역 아이콘을 누르고 자막 번역을 켭니다. 적절한 컨트롤 바가 없으면 영상 모서리에 버튼이 표시됩니다. YouTube에서는 먼저 기본 자막(CC)을 켜서 트랙을 불러오세요. 다른 플레이어에서도 자막 활성화가 필요할 수 있습니다. 제작자 자막과 지원되는 자동 생성 자막을 사용할 수 있고, 누적식 ASR 조각은 문장으로 합친 뒤 번역합니다.

원문과 번역을 영상 위에 표시하고 손잡이로 이동합니다. 위치는 전체 화면에서도 기억되며 표시 중인 플레이어 컨트롤을 피합니다. 재생 위치 근처 자막을 우선 번역하고 탐색 후 우선순위를 바꿉니다. 인식된 화자 이름은 번역에서 제외했다가 그대로 복원합니다. 지연은 제공업체와 영상에 따라 달라 고정 응답 시간을 보장하지 않습니다.

플레이어 메뉴와 **「설정 → 자막」**에서 이중 언어／원문만／번역만 표시, 줄 순서, 배경 불투명도와 각 줄의 크기·색상·글꼴·굵기를 설정합니다. 설정 페이지에는 실시간 미리보기, 정확한 숫자 입력, 작은 팔레트, HEX 입력 및 초기화 버튼이 있습니다.

<a id="languages"></a>
### 언어

**56개 번역 대상**과 위에 링크된 **14개 인터페이스 언어**는 별개입니다. UI는 브라우저 언어를 따를 수 있습니다. 팝업, 설정과 카드에서 언어의 자칭, 영어 이름, UI 언어 이름, 코드 및 영어 지역 별칭으로 검색할 수 있습니다. 오른쪽에서 왼쪽으로 쓰는 이름도 읽는 방향을 유지하며 메뉴 행은 정렬됩니다.

영어 대상은 **미국, 영국, 호주**로 나뉘며 이전 일반 `en` 설정은 미국 영어로 이전됩니다. 중국어는 **간체／번체**입니다. LLM에는 지역별 철자와 어휘를 명시합니다. 무료 서비스가 지역 변형을 지원하지 않으면 알림이나 제공업체 변경 없이 일반 영어로 대체합니다.

<a id="architecture"></a>
## 구조

<p align="center"><img src="./assets/framework.png" alt="BrowserTranslate 구조 및 제공업체 직접 연결" width="760"></p>

LLM과 기계 번역 요청은 **백그라운드 서비스 워커**에서 실행합니다. 웹사이트 JavaScript에는 API 키를 제공하지 않습니다. 콘텐츠 스크립트가 결과 표시와 페이지／플레이어 통합을 담당하며, 사이트별 자막 가져오기는 콘텐츠 또는 페이지 컨텍스트에서 실행될 수도 있습니다. 프로젝트가 운영하는 중계 서버는 없습니다.

<a id="installation"></a>
## 설치

현재 Chrome, Edge, Brave, Arc 등 **Chromium 기반 데스크톱 브라우저**용입니다. Firefox는 아직 지원하지 않습니다.

1. [Releases](https://github.com/Lewen-Cai/browser-translate/releases)에서 최신 `.zip`을 다운로드합니다.
2. 계속 유지할 폴더에 압축을 풉니다.
3. `chrome://extensions` 또는 브라우저 확장 관리 페이지에서 **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택한 뒤 해당 폴더를 지정합니다.

### 수동 업데이트

압축을 풀어 로드한 확장은 자동 업데이트되지 않습니다. 새 파일을 기존 폴더에 덮어 풀고 확장 페이지에서 **새로고침／다시 로드**를 누른 다음 열린 웹페이지도 새로고침하세요. Windows／macOS에서 관리형 방식으로 자체 호스팅 확장을 설치하려면 일반적으로 기업 정책이 필요하며, 압축 해제 폴더 로드와는 별도 절차입니다.

설정 상단에 설치된 버전과 수동 업데이트 확인 버튼이 있습니다. 눌렀을 때만 GitHub에 문의하고 새 버전이 있으면 파일을 제공합니다. 자동 설치하지 않으며 팝업에는 버전을 중복 표시하지 않습니다.

<a id="configuration"></a>
## 설정 방법

새 설치는 모든 모드에서 Microsoft를 사용합니다. 자신의 모델을 추가하려면 다음과 같이 진행합니다.

1. 팝업에서 설정 아이콘을 누릅니다.
2. **「제공업체」**에서 서비스를 활성화하고 엔드포인트, 모델, API 키를 입력합니다. 로컬 환경은 키가 필요 없습니다. 활성화된 행은 연결 상태／지연을 표시하며 이 확인은 해당 제공업체에 통신합니다.
3. **「번역 → 번역 엔진」**에서 선택 카드, 전체 페이지와 자막을 각각 지정합니다.
4. 대상 언어를 정하고 지원되는 페이지에서 텍스트와 파란 아이콘을 선택합니다. **「일반」**에서 단축키 모드를 켜면 기본 **Alt+T**는 선택 번역, **Alt+A**는 전체 페이지 번역입니다. 두 단축키 모두 해당 모드에서만 작동합니다.

팝업에는 대상 언어, 현재 페이지 스위치와 엔진 선택만 있습니다. 트리거 방식과 단축키는 설정에만 둡니다. 지원하지 않는 페이지는 번역을 비활성화하고, 콘텐츠 스크립트가 없으면 새로고침을 안내합니다. 프롬프트와 엔진 정책은 「번역」, 자격 증명은 「제공업체」, 자막 모양은 「자막」, 캐시와 가져오기／내보내기는 「데이터」에 있습니다.

### 제공업체와 추론 제어

**OpenAI, Claude, Gemini, DeepSeek, Moonshot, Zhipu, Qwen, SiliconFlow, OpenRouter, Mistral, opencode** 프리셋을 제공합니다. 로컬에서는 **LM Studio, Ollama, llama.cpp, vLLM** 등을 사용할 수 있으며 다른 호환 서비스는 사용자 엔드포인트로 연결합니다.

opencode Zen／Go, Qwen의 베이징·싱가포르·홍콩·미국 버지니아·Token Plan 등 지역과 요금제는 구분됩니다. 계정, 키, 모델 목록이 상호 호환되는 것은 아닙니다. 지원되는 제공업체는 워크스페이스 전용 URL도 입력할 수 있습니다.

지원되는 경우 기본으로 추론 끄기를 요청하고 **Low / Medium / High / XHigh / Max**를 제공업체 매개변수에 맞춥니다. 사용자／로컬 서버는 매개변수 형식을 선택하거나 「아무것도 보내지 않기」를 유지할 수 있습니다. 지원 제어를 보내지 않으면 서버 기본값이 적용됩니다. 실제 지원, 지연과 추론 토큰 과금은 UI 설정만이 아니라 모델과 엔드포인트에 달려 있습니다.

<a id="prompts"></a>
### 기본 프롬프트

**「번역 → 기본 프롬프트」**에는 템플릿 목록과 편집기가 나란히 있으며 좁은 화면에서는 위아래로 배치됩니다. 기본 템플릿은 읽기 전용입니다. **「새로 만들기」**에서 기본 내용을 복사하거나 빈 상태로 시작합니다. 설명은 편집기 아래에 있고, 템플릿 선택만으로 적용되지는 않습니다. 사용 중인 항목은 따로 표시합니다.

- **저장 및 적용**: 초안을 저장하고 바로 적용합니다.
- **변경 사항 저장**: 현재 사용 중인 프롬프트를 갱신합니다.
- **프롬프트 적용**: 저장된 템플릿을 적용하며 이미 사용 중이면 비활성화됩니다.
- **취소**: 로컬 편집을 버립니다.
- **템플릿 작업**: 적용하지 않고 저장, 복제, 기본 내용으로 초안 교체, 삭제를 제공합니다. 파괴적인 교체와 삭제는 확인이 필요하며 사용 중인 항목을 삭제하면 기본값으로 돌아갑니다.

사용자 지침은 기본 프롬프트에 덧붙는 것이 아니라 **대체**합니다. 대상 언어, 지역 규칙, 라우팅 및 출력 형식은 확장이 계속 추가하며 내부 프로토콜은 편집할 수 없습니다. 상충하는 지침이나 모델 성능에 따라 결과가 불완전할 수 있습니다. 일반 텍스트 편집기이므로 `{{...}}`를 치환하지 않습니다.

최대 **20개** 사용자 템플릿, 각각 **12,000자**의 지침을 로컬에 저장합니다. LLM에만 적용하며 Microsoft／Google 일반 번역에는 영향을 주지 않습니다. 지침이 바뀌면 별도 캐시를 사용하고, 설정 내보내기에는 템플릿과 현재 선택이 포함됩니다.

<a id="validation"></a>
### 응답 검증

명확한 긴 글에는 사전 지침을 보내지 않습니다. 짧은 선택은 모델이 판단하지만 사전 항목은 일부 단어가 아닌 전체 선택에 대응해야 합니다. 의심스러운 구조화 출력은 버퍼링 후 검증하며 카드에는 `{`로 추측하지 않는 명시적 결과 유형을 전달합니다.

선택 번역 형식 오류는 최대 **한 번의 일반 텍스트 수정 요청**으로 보완합니다. 페이지／자막 배치가 잘못되면 캐시에 없는 각 부분에 대해 최대 **한 번의 개별 텍스트 요청**을 사용합니다. 추가 토큰이 발생할 수 있으며 네트워크 재시도는 별도입니다. 계속 잘못된 경우 오류를 표시하고 원시 프로토콜 JSON을 번역처럼 보여 주거나 캐시하지 않습니다.

배치 ID는 빠짐없이 고유해야 하며 입력 순서로 재정렬됩니다. 숫자나 객체를 억지로 번역 문자열로 바꾸지 않습니다. 프로토콜별 캐시 키와 읽기 검증이 이전 미검증 결과를 격리합니다. 원문 자체가 구조화 데이터라면 텍스트로 번역할 수 있습니다.

**형식 검증은 의미 정확성이나 모든 누락 탐지를 보장하지 않습니다.** 원문 언어는 혼합 문자에 대한 보수적 표시를 포함한 로컬 추정일 뿐, 요청 차단이나 모드 결정에 사용하지 않습니다.

<a id="free-engines"></a>
### 무료 번역 서비스 안내

Microsoft와 Google은 `edge.microsoft.com`, `translate-pa.googleapis.com`의 공개 엔드포인트를 사용합니다.

- **공식 API가 아닙니다**: 각 회사의 웹／브라우저 번역용이며 본 확장에 대한 공개 계약은 없습니다.
- **제휴나 보증이 없습니다**: 프로젝트는 Microsoft／Google의 제휴·후원·승인 대상이 아닙니다. 이름과 상표는 소유자에게 속하며 선택한 서비스를 식별할 뿐입니다.
- **가용성은 보장되지 않습니다**: 예고 없이 변경되거나 중단될 수 있습니다. 자체 모델로 전환할 수 있으나 그 가용성도 제공업체에 달려 있습니다.
- **텍스트가 서비스로 전송됩니다**: 해당 약관과 개인정보 정책이 적용됩니다. 민감한 내용에는 적절한 자체 엔드포인트를 선택하세요.
- **무보증**: 있는 그대로 제공되며 사용 위험은 사용자에게 있습니다. 상업적 또는 대량 이용은 공식적으로 허가된 API를 사용하세요.

처음부터 사용할 수 있도록 Microsoft가 기본입니다. 특정 모드를 자신의 모델로 전환하면 그 모드는 위 공개 번역 엔드포인트를 더 이상 사용하지 않습니다.

<a id="privacy"></a>
## 개인정보와 로컬 데이터

중계 서버와 원격 측정이 없다는 것이 **모든 처리가 로컬이라는 뜻은 아닙니다**. 클라우드 제공업체는 요청한 텍스트를 받으며 로컬 실행 환경은 모델 처리를 컴퓨터 안에 둘 수 있습니다. 자막 가져오기는 영상 사이트에, 수동 업데이트는 GitHub에 연결합니다. 서비스는 IP 주소 등 일반적인 네트워크 메타데이터를 받습니다.

설정, API 키와 번역 캐시는 `chrome.storage.local`에 저장합니다. **확장은 API 키를 암호화하지 않습니다.** 내보내기는 기본적으로 키를 제외하지만 포함하면 평문 파일이 되므로 안전하게 보관해야 합니다. 캐시는 내보내지 않으며 열람 가능한 번역 기록 기능도 없습니다.

<a id="development"></a>
## 개발

```bash
pnpm install
pnpm dev          # 감시 빌드: .output/chrome-mv3-dev/
pnpm test         # 감시 모드 테스트
pnpm test:run     # 테스트 한 번 실행
pnpm typecheck    # WXT 타입 생성 + TypeScript
pnpm lint
pnpm build        # 프로덕션: .output/chrome-mv3/
```

출력 폴더를 압축 해제 확장으로 로드하세요. 빌드를 바꾸면 확장과 대상 페이지를 다시 로드합니다. [CHANGELOG.md](./CHANGELOG.md)에서 변경 내역을 보고 [Issues](https://github.com/Lewen-Cai/browser-translate/issues)에 문제와 제안을 남길 수 있습니다. 보고에서 API 키와 비공개 페이지 내용을 제거해 주세요.
