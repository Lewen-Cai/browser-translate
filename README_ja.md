<a id="why"></a>
## BrowserTranslate を選ぶ理由

拡張機能へのサブスクリプションや、当プロジェクトの中継サービスを使わずに、お好みの翻訳プロバイダーを利用できます。

- **モデルとキーを自分で選択**：OpenAI 互換エンドポイントやローカル実行環境に接続します。互換性はエンドポイントとモデルによって異なります。
- **直接接続**：翻訳するテキストはブラウザから選択したプロバイダーへ送信されます。当プロジェクトは中継サーバーを運営しません。
- **テレメトリなし**：利用分析、リモートへのエラー報告、リモートログ収集を行いません。
- **編集可能な基本プロンプト**：既定の内容を確認し、独自のテンプレートを作成できます。すべての LLM 翻訳で共通の基本指示を使用し、辞書や出力形式の内部規則は拡張機能が管理します。

<a id="features"></a>
## 機能

- **API キーなしで開始**：Microsoft と Google の翻訳サービスは最初から有効で、新規インストールでは3つの用途すべてが Microsoft を使います。非公式の公開エンドポイントのため、[無料サービスの注意事項](#free-engines)をご確認ください。
- **用途別のエンジン**：選択カード、ページ全体、動画字幕で別々のプロバイダーを選べます。複数の設定を保持し、切り替え時に再入力する必要はありません。
- **選択テキストの翻訳**：テキストを選択して浮動アイコンをクリックするか、ショートカットモードを使います。通常の訳文はストリーミング表示され、原文はその上に表示されます。コピー、再翻訳、プロバイダー、翻訳先をカード内で操作でき、一時的な選択は全体設定を変更しません。再翻訳はキャッシュを迂回します。
- **安定した移動可能なカード**：「全般 → 外観」でサイズを設定します。原文と訳文は個別にスクロールし、原文は本文領域の最大30%を占めます。待機中は小さな読み込み表示になります。ピン留めするとページのスクロールや外側のクリックでも閉じず、グリップで移動できます。
- **ページ全体の対訳表示**：ページ本文に訳文を挿入し、原文を上に残します。ナビゲーションやヘッダー、フッターは通常対象外です。スクロールに合わせて表示領域周辺を順次処理します。ポップアップの「現在のページ → 対訳表示」スイッチ、またはショートカットモードの **Alt+A** で切り替えます。
- **短い選択の辞書検索**：モデルは単語や短い用語の訳語、発音、品詞、意味、例文を返せます。明らかな段落、複数行、コードのような入力は翻訳専用です。通常の翻訳サービスは辞書項目を生成しません。
- **混在言語に対応**：原文と翻訳先が同じ言語でも要求を拒否しません。地域別表記への変換品質はモデルやサービスによります。
- **ローカル設定とキャッシュ**：「設定 → データ」で保存期間を変更できます。設定とプロンプトは JSON でエクスポート／インポート可能。キャッシュは含まず、API キーも明示的に選ばない限り除外します。
- **コンパクトな UI**：ライト／ダークをシステム連動または手動で選択。設定は全般、翻訳、プロバイダー、字幕、データの5ページです。UI はシステムフォント、コードやエンドポイントは等幅フォントを使います。

<a id="subtitles"></a>
### 動画字幕

**YouTube、Zoom のクラウド録画、Canvas の講義録画**、および標準の `<track>`／TextTrack で字幕を公開する互換プレーヤーの既存字幕を翻訳します。利用可否はプレーヤーとアクセス可能な字幕トラック次第で、すべての埋め込みプレーヤーを検証したわけではありません。**音声の文字起こしは行いません。**

プレーヤーの翻訳アイコンを押して字幕翻訳をオンにします。適切な操作バーがない場合、動画の隅にボタンが表示されます。YouTube では先に標準字幕（CC）をオンにしてトラックを読み込んでください。他のプレーヤーでも字幕の有効化が必要な場合があります。投稿者が用意した字幕と対応する自動字幕を利用でき、ローリング ASR の断片は文にまとめて翻訳します。

原文と訳文をプレーヤー上に重ね、グリップで移動できます。位置は全画面でも記憶され、操作バーの表示時にはそれを避けます。再生位置周辺を優先して翻訳し、シーク後は対象を組み直します。認識できた話者名は翻訳から外してそのまま戻します。遅延は動画とプロバイダー次第で、固定時間での応答は保証しません。

プレーヤーメニューと**「設定 → 字幕」**で、対訳／原文のみ／訳文のみ、上下の順序、背景の不透明度、各行のサイズ・色・フォント・太さを変更できます。設定ページにはライブプレビュー、正確な数値入力、小さなパレット、HEX 入力、リセットボタンがあります。

<a id="languages"></a>
### 言語

**56の翻訳先**と上部に並ぶ **14の UI 言語**は独立しています。UI はブラウザの言語にも追従できます。ポップアップ、設定、カードの言語検索は、自称、英語名、UI 言語での名称、コード、英語の地域別呼称に対応します。RTL の名前は読み方向を保ち、行の配置は揃います。

英語は**米国・英国・オーストラリア**に分かれ、以前の汎用 `en` は米国英語へ移行します。中国語は**簡体字・繁体字**です。LLM には地域の綴りや語彙を指示します。無料サービスが地域差に対応しない場合は、通知やプロバイダー変更なしで汎用英語を使います。

<a id="architecture"></a>
## アーキテクチャ

<p align="center"><img src="./assets/framework.png" alt="BrowserTranslate の構成とプロバイダーへの直接接続" width="760"></p>

LLM・機械翻訳の要求は**バックグラウンドの Service Worker**が送信し、ウェブサイトの JavaScript に API キーを渡しません。コンテンツスクリプトが結果表示とページ／プレーヤー統合を担当します。サイト固有の字幕取得はコンテンツまたはページのコンテキストで動作する場合もあります。プロジェクトの中継サーバーはありません。

<a id="installation"></a>
## インストール

現在は Chrome、Edge、Brave、Arc などの **Chromium ベースのデスクトップブラウザ**向けです。Firefox は未対応です。

1. [Releases](https://github.com/Lewen-Cai/browser-translate/releases) から最新の `.zip` をダウンロードします。
2. 継続して使うフォルダーへ展開します。
3. `chrome://extensions` またはブラウザの拡張機能ページで**デベロッパーモード**を有効にし、**パッケージ化されていない拡張機能を読み込む**からそのフォルダーを選びます。

### 手動更新

展開して読み込んだ拡張機能は自動更新されません。新しいアーカイブを既存フォルダーへ上書き展開し、拡張機能ページで**再読み込み**、続いて開いているウェブページを更新してください。Windows／macOS の管理された自己ホスト型インストールは一般に企業ポリシーが必要で、展開済みフォルダーの読み込みとは別の仕組みです。

設定ページ上部にバージョンと手動更新チェックがあります。押したときだけ GitHub に問い合わせ、新版があればアーカイブを案内します。自動インストールはしません。ポップアップにはバージョンを重複表示しません。

<a id="configuration"></a>
## 設定方法

初期状態ではすべて Microsoft を使います。自分のモデルを使うには：

1. ポップアップの設定アイコンを開きます。
2. **「プロバイダー」**でサービスを有効にし、エンドポイント、モデル、API キーを入力します。ローカル環境はキー不要です。有効な行は接続状態／遅延を表示し、この確認はプロバイダーに通信します。
3. **「翻訳 → 翻訳エンジン」**で選択カード、ページ全体、字幕を個別に割り当てます。
4. 翻訳先を選び、対応ページの文字を選択して青いアイコンを押します。キーボード操作は**「全般」**でショートカットモードを選択。既定は選択翻訳 **Alt+T**、ページ全体 **Alt+A** で、どちらもこのモードでのみ有効です。

ポップアップには翻訳先、現在ページの対訳スイッチ、エンジン選択だけを置きます。起動方法とショートカットは設定専用。非対応ページでは翻訳を無効にし、スクリプト未準備時は再読み込みを案内します。基本プロンプトと割り当ては「翻訳」、認証情報は「プロバイダー」、字幕の外観は「字幕」、キャッシュと入出力は「データ」です。

### プロバイダーと思考制御

**OpenAI、Claude、Gemini、DeepSeek、Moonshot、Zhipu、Qwen、SiliconFlow、OpenRouter、Mistral、opencode** のプリセットを用意。ローカルには **LM Studio、Ollama、llama.cpp、vLLM** などを使え、他の互換サービスはカスタムエンドポイントで接続します。

opencode Zen／Go、Qwen の北京・シンガポール・香港・米国バージニア・Token Plan など、地域やプランは別のエンドポイントです。アカウント、キー、モデル一覧は相互利用できるとは限りません。対応プロバイダーではワークスペース固有 URL も入力できます。

制御対応時は既定で思考オフを要求し、**Low / Medium / High / XHigh / Max** をプロバイダーのパラメーターへ変換します。カスタム／ローカル環境ではパラメーター形式か「送信しない」を選びます。有効な制御を送らない場合はサーバー側の既定動作です。対応状況、速度、推論トークンの課金はモデルとエンドポイントに依存し、UI 設定だけでは保証できません。

<a id="prompts"></a>
### 基本プロンプト

**「翻訳 → 基本プロンプト」**にテンプレート一覧とエディターがあります。狭い画面では縦に並びます。既定は閲覧専用で、**「新規」**から既定を元に作るか空白から始めます。説明はエディター下にあり、選択するだけでは適用されません。使用中のものは別途表示します。

- **保存して適用**：下書きを保存し、そのまま適用。
- **変更を保存**：使用中のプロンプトを更新。
- **プロンプトを適用**：保存済みテンプレートを適用。使用中なら無効。
- **キャンセル**：ローカル編集を破棄。
- **テンプレート操作**：適用せず保存、複製、既定の文章で下書きを置換、削除。破壊的な置換／削除は確認が必要で、使用中の削除は既定に戻ります。

独自の指示は基本プロンプトを**置き換え**、追記するのではありません。翻訳先、地域差、ルーティング、出力形式は拡張機能が追加し、内部プロトコルは編集できません。矛盾した指示や弱いモデルでは結果が不完全になり得ます。`{{...}}` の変数置換は行いません。

**20個**まで、各 **12,000文字**までのカスタムテンプレートをローカル保存できます。LLM 専用で Microsoft／Google の通常翻訳には作用しません。指示変更は別キャッシュになり、エクスポートにはテンプレートと適用中の選択を含みます。

<a id="validation"></a>
### 応答の検証

明らかな文章には辞書指示を送りません。短い選択はモデルが判断しますが、辞書の見出し語は選択全体と対応する必要があります。疑わしい構造化出力は一旦保持して検証し、カードは `{` ではなく明示的な結果型で表示方法を決めます。

選択の形式エラーには最大**1回のプレーンテキスト修正要求**を行います。ページ／字幕の不正なバッチは、未キャッシュの各部分につき最大**1回の個別テキスト要求**へ切り替えます。追加トークンが必要な場合があり、通信エラーの再試行は別枠です。修正後も不正ならエラーを表示し、生のプロトコル JSON を訳文として表示・保存しません。

バッチ ID は欠落・重複がなく、結果を入力順に戻せる必要があります。数値やオブジェクトを無理に文字列化しません。プロトコル別キャッシュキーと読み込み時の検証で以前の未検証結果を分離します。原文そのものの構造化データはテキストとして翻訳できます。

**形式検証は意味の正確さや漏れの完全検出を保証しません。** 言語ラベルはローカルな表示上の推定で、混在文字も保守的に示しますが、要求の阻止やルーティングには使いません。

<a id="free-engines"></a>
### 無料翻訳サービスについて

Microsoft／Google は `edge.microsoft.com` と `translate-pa.googleapis.com` の公開エンドポイントを使用します。

- **公式 API ではありません**：各社のウェブ／ブラウザ翻訳用で、本拡張向けの公開契約はありません。
- **提携・承認はありません**：本プロジェクトは Microsoft／Google の関連・スポンサー・公認プロジェクトではありません。名称や商標はサービスの識別用で、権利者に帰属します。
- **継続利用を保証しません**：予告なく変更・停止する場合があります。自分のモデルへ切り替えられますが、その可用性も提供元次第です。
- **テキストをサービスへ送信します**：各社の利用規約・プライバシーポリシーが適用されます。機密情報には適切な独自エンドポイントを選んでください。
- **無保証**：現状のまま提供し、利用は自己責任です。商用・大量利用には正式に認可された公式 API を使用してください。

初回から使えるよう Microsoft を既定にしています。ある用途を自分のモデルへ切り替えると、その用途はこれらの公開翻訳エンドポイントを使わなくなります。

<a id="privacy"></a>
## プライバシーとローカルデータ

中継やテレメトリがないことは、**すべての処理がローカルという意味ではありません**。クラウド提供元には依頼したテキストが送られ、ローカル環境ならモデル処理を端末内に保てます。字幕取得は動画サイト、手動更新チェックは GitHub に接続します。接続先は IP アドレスなど通常の通信メタデータを受け取ります。

設定、API キー、翻訳キャッシュは `chrome.storage.local` に保存されます。**拡張機能は API キーを暗号化しません。** エクスポートは既定でキーを除外しますが、含めると平文ファイルになるため厳重に管理してください。キャッシュはエクスポートされず、閲覧可能な翻訳履歴機能もありません。

<a id="development"></a>
## 開発

```bash
pnpm install
pnpm dev          # 監視ビルド：.output/chrome-mv3-dev/
pnpm test         # 監視モードでテスト
pnpm test:run     # テストを1回実行
pnpm typecheck    # WXT の型生成 + TypeScript
pnpm lint
pnpm build        # 本番ビルド：.output/chrome-mv3/
```

出力フォルダーを展開済み拡張として読み込み、ビルド変更後は拡張と対象ページを再読み込みしてください。[CHANGELOG.md](./CHANGELOG.md) に変更履歴、[Issues](https://github.com/Lewen-Cai/browser-translate/issues) に不具合や要望を記載できます。報告から API キーや非公開のページ内容を取り除いてください。
